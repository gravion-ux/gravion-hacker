# Pro and Support

Maintainer: Priyanshu Kumar Thakur

## Why a paid option exists here

Consultants and bounty hunters produce client-facing reports where consistent, polished reporting and support save billable time. The free version below stays complete for local use; nothing in the free core is removed or crippled to force an upgrade.

## Free (this repository)

- Offline-first authorised assessment modules in this repository
- Evidence, scoring and report generation
- Scope and authorisation helpers
- Local web view for supplied findings

## Paid / supported option

- Advanced report-template packs for client delivery
- Priority support for authorised engagements
- Team report-review workflow guidance

Paid features are offered as support, setup help, templates, or a hosted service where stated. They are not hidden gates inside the free code in this repository.
